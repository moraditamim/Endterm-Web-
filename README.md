# Study Circle — Endterm project

A two-page, static front-end website continued from the Midterm project.

## Run locally
Open `index.html` in a browser, or serve this folder with a local static server.

## Pages
- `index.html` — Home and club information.
- `workshops.html` — searchable workshops, filters, sorting, learning-plan calculator, sample timetable and demo signup form.

## Endterm features
- Eight workshop objects stored in `js/main.js` and rendered through DOM manipulation.
- Search, category filter and sorting without a page reload.
- A learning plan that calculates selected workshop count and total minutes.
- A validated demonstration form with inline field errors and a success preview.
- jQuery slide, fade and smooth-scroll effects.
- Responsive Bootstrap layout with custom styles and keyboard focus states.

## Project structure
- `css/` — custom stylesheet.
- `js/` — application JavaScript.
- `assets/vendor/` — local Bootstrap and jQuery files and their licenses.
- `assets/fonts/` — local font files and licenses.
- `docs/screenshots/` — screenshot capture checklist and the six final screenshot slots.
